Date: 2026-11-01

Scope
These changes address the review findings in the Qt-free web implementation.
The original pyrpl hardware modules and FPGA RTL are reference material and
are unchanged. No bitstream rebuild is required. No deployment or electrical
verification was performed: the Red Pitaya is unavailable.

ASG DDS fix carried into this commit
The earlier uncommitted fix establishes the full 2^30 phase modulus and enables
remainder-preserving wrap, including settings restored without a Setup click.
It repairs the missing original initialization that produced the 2 MHz cycle
boundary glitch. Ordinary frequency tuning does not rewrite the shared ASG
control register unnecessarily. The original RTL already supports normal DDS.

Shared measurements and protocol
Scope WebSocket frames remain PWS1 float32 interleaved channels. They now contain
shared averaged samples, so the web client must not average them a second time.
A smaller samples query covers the same whole capture, not a second acquisition.

With trace_average=1, Spectrum retains the lightweight PWS1 raw-sample path.
With trace averaging enabled it uses PWA1 for shared averaged correlations: 4-byte magic, uint32 LE
JSON-header size, JSON padded to an 8-byte boundary, then float64 LE rows of
length 2*N. Metadata includes samples, sequence, count, baseband, span, center,
iqBandwidth and window. Baseband rows encode channel-1 autocorrelation,
channel-2 autocorrelation, even cross correlation and odd cross correlation.
IQ mode carries real/imaginary autocorrelation. The browser pads correlations
and performs the display FFT, producing the same 16x-padded powers as averaging
raw-record FFTs. Float64 protects the spectral dynamic range from cancellation.
All supported window averages are updated from the same captures, with bounded
memory independent of trace_average. Window selection is a read-only query.
Changing Scope/Spectrum trace_average starts a fresh average without restarting
the current acquisition mode.

Network Analyzer messages are individual point objects or {snapshot: [points]}.
The bundled client accepts both and preserves the completed curve on reconnect.

GET /api/scope/frame is a passive cached read (204 before any measurement).
GET /api/spectrumanalyzer/frame?window=blackman is likewise a cached read,
returning the complete averaged spectrum in Vpk^2 (204 before any measurement).
The legacy Spectrum samples/sequence query no longer controls acquisition.
Update external consumers of these interfaces together with the server.

Validation
See final recorded results below and REDPITAYA_PARITY_HARDWARE_CHECKS_2026-11-01.txt.
Hardware correctness and board throughput remain unverified until that checklist
is run. Existing offline tests use the fake client, register simulations and
original PyRPL design math; these do not establish electrical performance.

Board performance considerations
Averaged Spectrum records use bounded correlation storage for five windows.
For N=16384, an unaveraged PWS1 message is about 128 KiB; a baseband PWA1 message is approximately 1 MiB per observer. The
measured all-window calculation on this development PC was about 14 ms/record;
this is not a Red Pitaya estimate. Measure ARM CPU/RAM, network throughput and
control latency with the desired trace interval before relying on that rate.
